# Agro Scoring API

Практическое занятие №1: REST API для оценки риска сельхозпредприятий на FastAPI.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Swagger: http://127.0.0.1:8000/docs

## Endpoints

- GET /health
- GET /model-info
- POST /predict
- GET /predictions
- GET /predictions/{request_id}
